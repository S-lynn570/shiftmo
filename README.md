# シフトモ：PHP初学者向け・最も簡単な版

## 起動方法
1. この `shiftmo_php` フォルダを XAMPP の `htdocs` に入れます。
2. XAMPP で Apache を起動します。
3. `http://localhost/shiftmo_php/` を開きます。

## ファイルの読み方
1. `login.php`：ログイン画面のHTMLとログイン処理
2. `DAO/LoginDAO.php`：最初に使う固定データ
3. `home.php`：ホームのHTML（通知のみ）
4. `DAO/HomeDAO.php`：ホームの通知データ取得
5. `shifts.php`：月間カレンダーのHTML
6. `DAO/ShiftsDAO.php`：表示する年月の計算
7. `CSS/shifts.css`：月間カレンダーの余白や大きさ

**各画面は「①セッション → ②ログイン確認 → ③DAO読み込み → ④HTML表示」の順番です。**

- `common.php`、`store.php`、JSONは使いません。
- DAOの中に多数の共通関数を置かず、各ページの処理を直接書いています。
- HTMLを `echo` で長くつなげず、PHPとHTMLを分けています。
- ナビゲーションは理解しやすいように各ページに同じHTMLを記載しています。
- データはPHPの `$_SESSION` に保存します。ブラウザやセッションが変わるとデータは共有できません。
- データベース、メール送信、複数人での同時利用、実運用の安全対策は未実装です。
- PHP学習用のデモです。個人情報を登録して本番運用しないでください。

## CSSの見方
各画面のPHPから、対応するCSSを1つだけ読み込みます。例：`home.php` → `CSS/home.css`。
`common.css`は使用しません。各CSSに基本デザインも書いてあるため、重複がありますが、初心者が1ファイルだけ読んで理解できるようにしています。

## 設計図に合わせた操作順
1. 店長も従業員も「シフト希望登録」で自分の希望のみ確認・登録します。
2. 店長は「シフト管理 → シフト編集」で従業員の希望を確認し、勤務シフトを作成します。
3. 「シフト公開」を押すと従業員が公開シフトを確認できます。
4. 公開後、従業員は「シフト変更申請」から自分の公開シフトの変更を依頼できます。
5. 店長は「シフト調整依頼一覧」で承認または拒否します。承認時に公開シフトを更新します。
6. 「部署管理」は登録・部署設定・部署別確認の3画面に分かれています。

対象日の表示はブラウザのパソコン日付です。打刻の記録時刻はPHPサーバーの時刻です（通常、同じPC上のXAMPPなら一致します）。
データはセッション内だけに保存されます。別のブラウザ間での共有や実際のメール送信はできません。

## 旧版セッションの互換対応
manage_shifts.php は旧版の希望・シフト・変更申請にIDがない場合、IDを追加します。
変更申請に shift_id がない場合は誤ったシフトを更新しないよう承認操作を表示しません。
過去のテストデータを初期化したい場合は、ログアウト後にブラウザーのサイトデータを削除して再ログインしてください。


## 共通デザインの変更方法

- 全ページの見た目は `CSS/design.css` でまとめて調整しています。
- 各PHPページで、元のCSSの次に `design.css` を読み込みます。後から読み込むCSSが優先されます。
- 背景色は `background`、文字色は `color`、内側の余白は `padding`、外側の余白は `margin`、角の丸みは `border-radius` です。
- `:hover` はマウスを重ねたとき、`:focus` は入力欄を選択したときの見た目です。
- `.sidebar a.active` は現在のページのメニューです。リンク先や処理は変えていません。
- `@media (max-width: 800px)` の中は、幅が狭い画面用の設定です。
- 外部ライブラリや新しいJavaScriptは使っていません。PHPの処理、入力項目、登録方法は変更していません。


## 従業員管理の画面の流れ

1. `employees.php`：新規登録・一覧の2つの入口です。
2. `employee_new.php`：従業員名・連絡先・E-mail・部署を入力します。登録ボタンでは、まだ保存しません。
3. `employee_confirm.php`：内容を確認します。戻ると入力を修正できます。確認ボタンで保存します。
4. `employee_list.php`：登録後に従業員IDをポップアップ表示します。ID・氏名で検索でき、各行から編集・削除できます。
5. `employee_edit.php`：選んだ従業員を編集します。ID・権限・パスワードは変えません。

処理は今までと同じ `DAO/EmployeesDAO.php` にまとめています。新規登録の仮入力は `employee_draft`、登録済みデータは `employees` のSessionに保存します。初期パスワードは従来どおり `password123`、権限はSTAFFです。
ログイン中の本人や、シフト・勤怠・申請・通知などの記録がある従業員は、記録との関連を守るため削除できません。メールアドレスの重複は登録できません。
